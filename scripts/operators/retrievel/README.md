# RetrieVEL source operator

Use this local operator to receive complete named source from the existing
graph-find adapter. Read the [operator guide](OPERATOR_GUIDE.md) for launch,
result, stop and saved-evidence instructions.

The client supports bounded multiple uniquely admitted targets in one native
session and one inherited allowance. It prints COMPLETE, PARTIAL, FAILED or
INTERRUPTED after saving the receipt. It lists accepted full-file references,
hashes, the last accepted content charge and the evidence location.

Pass the interpreter, native tool, source root and external evidence root
explicitly. Evidence stays in a fresh directory below the selected owned root.
The client refuses output inside the source repository or operator checkout.
It preserves existing evidence. No server, provider, installation or persistent
index is required.

This source-only entrypoint composes the reviewed U6 source-delivery behavior
and U7 terminal result. It is separate from the installed graph-engineering
plugin version 0.1.6. It does not change installed command discovery or run an
answer model, evaluator, repository tests or CI.

Missing and ambiguous targets refuse before native startup. U13 candidate
selection remains absent. The optional `--follow-imports` accepts one pending
target only and uses a cached syntactic Python witness. It does not establish
runtime import binding or current importer freshness.

Source delivery is not semantic completeness, an answer, or proof of cost or
quality benefit. Keep the input handoff with all responses and the receipt.
